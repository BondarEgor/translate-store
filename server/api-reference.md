# API «Хранилище переводов»

Базовый URL: `/api`. Все запросы и ответы — `application/json`.

## Конвенции

**Формат ошибки** (всегда одинаковый):

```json
{ "error": { "message": "Ключ «hero.title» уже существует" } }
```

**Коды ответов:**

| Код | Когда |
|---|---|
| `200` | успешное чтение/обновление |
| `201` | ресурс создан |
| `204` | успешное удаление (тела нет) |
| `400` | ошибка валидации тела запроса |
| `404` | ресурс не найден |
| `409` | конфликт (дубликат) |
| `500` | внутренняя ошибка |

Клиент просто показывает `error.message` пользователю; при отсутствии сообщения — свой дефолтный текст.

## Снимок хранилища

### `GET /api/state`

Всё для первого рендера одним запросом.

**Ответ `200`:**

```json
{
  "defaultLocale": "ru",
  "locales": [{ "code": "ru", "isDefault": true, "total": 128, "missing": 0, "percent": 100 }],
  "namespaces": [{ "name": "home", "keys": 34 }],
  "stats": { "languages": 2, "tables": 4, "keys": 128, "missing": 3 }
}
```

---

## Таблицы (неймспейсы)

### `GET /api/namespaces`

**Ответ `200`:** `[{ "name": "home", "keys": 34 }]`

### `POST /api/namespaces`

Создаёт таблицу. Тело: `{ "name": "home" }`. Ответ `201`: `{ "name": "home" }`. Ошибки: `409` — уже существует.

### `PATCH /api/namespaces/:name`

Переименовывает таблицу во всех языках. Тело: `{ "name": "new-home" }`. Ответ `200`: `{ "from": "home", "to": "new-home" }`. Ошибки: `404`, `409`.

### `DELETE /api/namespaces/:name`

Удаляет таблицу вместе со всеми переводами. Ответ `204`.

---

## Языки (локали)

### `GET /api/locales`

**Ответ `200`:** `[{ "code": "ru", "isDefault": true, "total": 128, "missing": 0, "percent": 100 }]`

### `POST /api/locales`

Добавляет язык: копирует все ключи с основного языка и переводит. Тело:

```json
{ "code": "es", "translate": true }
```

**Ответ `201`:** `{ "locale": "es", "keys": 128, "translated": 125, "providerUsed": true }`. Ошибки: `409` — уже есть, `400` — код языка невалиден.

### `DELETE /api/locales/:code`

Удаляет язык и все его переводы. Ответ `204`. Ошибки: `400` — попытка удалить основной язык.

## Переводы (строки ключей)

### `GET /api/namespaces/:name/translations`

**Ответ `200`:**

```json
[{
  "ns": "home",
  "key": "hero.title",
  "values": { "ru": "Заголовок", "es": "Título" },
  "missing": []
}]
```

`missing` — список языков без перевода этой строки.

### `POST /api/translations`

Создаёт ключ сразу во всех языках (перевод автоматический). Тело:

```json
{ "namespace": "home", "key": "hero.title", "locale": "ru", "value": "Заголовок" }
```

**Ответ `201`:** `[{ "namespace": "home", "key": "hero.title", "locale": "ru", "value": "Заголовок" }, …]` — все созданные строки. Ошибки: `409` — ключ существует, `400` — невалидный ключ.

### `PUT /api/translations`

Обновляет значение основного языка **и заново переводит все остальные** (upsert: недостающие строки создаются). Тело — то же, что у POST. Ответ `200` — массив обновлённых строк.

### `PATCH /api/translations`

Ручная правка **одной строки** в конкретном языке (машинный перевод не вызывается). Тело — то же. Ответ `200`.

### `PATCH /api/keys`

Переименовывает ключ во всех языках. Тело: `{ "namespace": "home", "key": "hero.title", "newKey": "hero.heading" }`. Ответ `200`: `{ "newKey": "hero.heading", "updated": 2 }`. Ошибки: `404`, `409`.

### `DELETE /api/keys`

Удаляет ключ из всех языков. Тело: `{ "namespace": "home", "key": "hero.title" }`. Ответ `204`.

## Синхронизация

### `POST /api/sync`

Допереводит все недостающие (`missing`) строки всего хранилища. Тела нет.

**Ответ `200`:**

```json
{ "report": { "es": 3, "de": 1 } }
```
