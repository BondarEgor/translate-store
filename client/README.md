# Хранилище переводов

Админка для таблиц переводов одного проекта: неймспейсы → плоские ключи → значения
по языкам. Данные живут в **Supabase Postgres**, админка — на русском, стек —
**Vite + React + TypeScript**, UI-компоненты — **Radix Themes** (npm-пакет,
исходников библиотеки в репо нет, никакого Tailwind и CSS Modules).

## Возможности

- Таблицы (неймспейсы) — создавать, переименовывать, удалять со всем содержимым;
- внутри таблицы — **один язык за раз**: основной редактируется кликом по ячейке,
  остальные смотрим в read-only и добиваем кнопкой «Разослать недостающие»;
- ключи — добавить (автоматом переводится и разлетается по языкам),
  **переименовать**, отредактировать значение, удалить из всех языков;
- языки — добавить в один клик: копия всех ключей основного языка + авто-перевод
  (ICU-плейсхолдеры `{count, plural, …}` машинно не переводятся — синтаксис защищён);
- поиск по ключу и тексту, статус-точки полноты, длинные ключи не ломают вёрстку.

## Быстрый старт

```bash
npm install
cp .env.example .env   # вписать SUPABASE_URL + SUPABASE_SECRET_KEY
npm run dev            # http://localhost:5173 (API встроено в Vite)
```

Схема БД — `supabase/schema.sql` (SQL Editor в дашборде, один раз).
Залить сид из `messages/*.json` в базу: `npm run migrate` (идемпотентно).

## Архитектура

```
src/                      клиент
├── main.tsx              точка входа (+ стили themes и базовый index.css)
├── app.tsx               Theme + каркас: сайдбар слева, таблица справа
├── store.ts              стор-хук: снимок, ключи, все действия API с тостами
├── api.ts                типы + эндпоинты (`api.*`)
├── index.css             5 строк базы: --background/--text, шрифт
├── components/           app-sidebar, keys-table, confirm-dialog
└── lib/                  plural.ts
server/                   Vite-плагин API: store (Supabase), translate (авто-перевод)
scripts/                  migrate-to-supabase.ts (сид → БД)
```

Правила в коде: файлы и папки в kebab-case, импорты только прямые (алиас `@/`),
без barrel-файлов. Все стили — пропсы Radix Themes (`variant`, `color`,
`highContrast`), палитра — ч/б через токены темы и `--background`/`--text`.

## Безопасность

- Secret key используется **только** на сервере (Vite-плагин), `.env` в gitignore.
- На чтение извне: RLS-политики `SELECT` для anon — читать можно publishable-ключом
  (это же ключ в браузере вашего приложения), записи через anon нет.
- Удаление таблицы забирает все её переводы каскадом — в UI двухшаговое подтверждение.
